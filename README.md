# 酒馆阅读助手 v15.0（主页面扩展版）

此版本应作为 SillyTavern/TauriTavern 的 UI 扩展运行，而不是粘贴到酒馆助手的隔离全局脚本中。

## 功能
- 主页面紫色悬浮耳机球、深色玻璃控制面板
- 浏览器语音朗读 AI 消息、上一句/下一句/暂停/停止
- 字幕开关、逐句高亮、跟随滚动
- 悬浮球和字幕可拖动，位置保存在 localStorage

## 安装提示
标准 SillyTavern 的第三方扩展安装器通常要求一个 Git 仓库 URL；本 ZIP 是扩展文件包，不是可直接粘贴到 Git URL 输入框的地址。
如果 TauriTavern 的扩展管理页面提供“本地导入/上传扩展”，选择本 ZIP；如果没有，需要把解压后的文件夹放进它的扩展目录（文件夹内必须直接包含 manifest.json 和 index.js），然后重启/刷新并在扩展管理中启用“酒馆阅读助手”。
不同 TauriTavern 构建版的扩展目录和安装方式可能不同，请不要覆盖现有扩展文件。
