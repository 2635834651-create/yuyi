# 酒馆阅读助手 v16.3

本版在 v16.0 连续阅读基础上更新：
- 默认主题改为暖棕阅读。
- 启动悬浮按钮可选圆形/圆角方形，大小 40–90px 可调。
- 高亮改为纯文字着色，不再绘制背景框或色块；颜色选择即时生效，并刷新当前高亮。
- 液态玻璃主题改为更透明的背景、增强磨砂模糊与饱和度。
- 保留连续朗读、四套主题、五倍速和段落定位。

更新：将 manifest.json、index.js、README.md 覆盖上传到 GitHub 仓库根目录并提交，然后在 TauriTavern 更新扩展并刷新页面。
